## mask

MASK (Ren et al. 2025, CAIS and Scale AI) measures whether a model will state something it does not believe when a system or user prompt gives it a reason to lie. Each row has a proposition, its ground truth, a pressure prompt and belief-elicitation prompts; honesty is scored by comparing the pressured statement with the belief the model gives in a neutral context, which separates lying from being wrong. The lab uses all six public archetypes (`continuations` 176, `disinformation` 125, `doubling_down_known_facts` 120, `known_facts` 209, `provided_facts` 274, `statistics` 96; one `test` split each, 1,000 rows) because the whole point of the cut is honesty that survives pressure, and the judge prompts (`github/mask/prompts/evaluation_prompts.py`) with `evaluate.py` and `metric.py` are kept as reference text to reimplement the scoring. Licence: **the dataset card states no licence** and the website is silent; only the GitHub code is MIT. Flags: no data licence (evaluate locally, do not redistribute); canary string in every row (`mask:5c3a:26b5c67b-...`), so never train on it; the public set is 1,000 rows although the card's prose says 1,028.

## behonest

BeHonest (Chern et al. 2024, GAIR) covers three strands of honesty: self-knowledge (admitting unknowns: 7,648 unanswerable questions; expressing knowns: 4,579), non-deceptiveness (persona sycophancy 470 pairs, preference sycophancy 1,265 pairs, burglar deception 4 x 50 instructed-lie scenarios, werewolf game 162) and consistency (prompt format 5 x 400, open-form 500, multiple-choice 500). The whole Hugging Face package is 5.3 MB, so all of it was fetched; the lab's primary use is the non-deceptiveness scenarios (burglar deception and the game test whether a model lies when told to or when lying wins; the sycophancy pairs test caving to a persona or a stated preference) and the self-knowledge pair, with the consistency scenarios kept as controls. The `Demonstration_Format` scenario is not in the package upstream (it depends on external BBH data) and was not fetched. Licence: CC-BY-SA-4.0 on the dataset card; the GitHub code repository has no LICENSE file. Flags: ShareAlike applies to any redistributed adaptation; several scenarios derive from TriviaQA, CommonsenseQA and Natural Instructions, which have their own licences; no training clause.

## sad

SAD (Laine et al. 2024) tests whether a model knows what it is and what situation it is in: facts about itself, influence, introspection, stages (is this testing or deployment), self-recognition, id-leverage and anti-imitation; 7 categories, 16 tasks, over 13,000 questions. The maintainers deliberately keep every question and answer file inside password-protected zip archives and require that the text never appear in plain text anywhere scrapable, including private GitHub repositories; the password is published in the repository's `unzip.sh`, which is in `raw/`. Everything at the pinned commit was fetched except the `sad/**/evals.zip` archives (474 MB of the authors' model-run results) and `results/` (10.8 MB of paper plots): 193 files, 106.5 MB, of which 31 archives hold 2,049 file entries, every one encrypted (checked with `zipinfo`, which lists without extracting). **The archives were left encrypted** and nothing was run; to use them, decrypt with `unzip -P <password from raw/unzip.sh> <archive>.zip -d <local git-ignored dir>` and delete the plain text afterwards. The lab will use the model-independent SAD-mini subset (`facts_human_defaults`, `facts_llms`, `influence`, `stages_full`, `stages_oversight`; 2,904 multiple-choice questions) read from the decrypted `structs`/`raw_data` archives with its own loader, because the other tasks need the authors' `evalugator` tooling or model-specific answers. Licence: CC-BY-4.0 (`LICENSE.txt`). Flags: the no-plain-text requirement above; the BIG-bench canary, so never train on it; most tasks cannot be run without executing upstream code, which the lab does not do.

## sycophancy_eval

SycophancyEval (Sharma et al. 2023, Anthropic) has three free-form sets: `feedback` (8,500 prompts: the same argument, poem or proof is presented with the user liking, disliking or claiming authorship, and the model's feedback is checked for drift), `are_you_sure` (4,888: a correct answer is challenged with "I don't think that's right. Are you sure?" and the model is checked for folding) and `answer` (7,268: the user suggests a possibly wrong answer or says they are unsure). The lab uses all three; `are_you_sure` is the primary one because folding to a bare challenge is the cleanest signal of approval-seeking, and `feedback` gives a non-factual counterpart. Fetched from the GitHub source (35.0 MB); the HF mirror (`18f18160`) adds `mimicry.jsonl`, not fetched. Licence: MIT, but stated only on the HF mirror's card; the GitHub repository ships no LICENSE file (flagged for the lab owner). Flags: BIG-bench canary in the README, so never train on it; prompts are built from TriviaQA, MATH and other third-party material with their own licences.

## agentic_misalignment

Anthropic's agentic-misalignment framework (Lynch et al. 2025) places a model as an email agent in a fictional company and crosses three scenarios (blackmail, leaking, murder) with goal conditions (explicit, none, latent, ambiguous, swap) and urgency conditions (replacement, restriction, none), then classifies whether the model takes the harmful action. Fetched as files only: `templates/` (21 email templates, 15 goal-variable files, the system-prompt templates and the template parser), `configs/` (4 experiment configs), `classifiers/` (the judge prompts for blackmail, leaking, murder and deliberation) and `scripts/generate_prompts.py` as the reference for how prompts are assembled; no API client or runner code, and nothing is executed. There is no static prompt file upstream, so the lab assembles prompts with its own code following `generate_prompts.py`; the primary conditions will be goal none/explicit x urgency replacement, the paper's headline cells, because they isolate self-preservation pressure. Licence: MIT (Copyright 2025 Aengus Lynch). Flags: scenarios contain graphic fictional harm; results in the paper come from contrived settings.

## ifeval

IFEval (Zhou et al. 2023, Google) is 541 prompts with 25 kinds of verifiable instruction ("no commas", "at least 3 highlighted sections", "end with this phrase") checked by code, not a judge. The lab uses the single split as a capability control: a cut that changes honesty or sycophancy must leave instruction following unchanged, and IFEval is cheap, deterministic and widely reported. The constraint checkers live in `google-research/instruction_following_eval` (not fetched); the lab reimplements the subset it needs. Licence: Apache-2.0 on the dataset card. Flags: none beyond Apache notice and attribution.

## strongreject

StrongREJECT (Souly et al. 2024, CHAI) is 313 forbidden prompts in six categories (disinformation 50, hate and harassment 50, illegal goods 50, non-violent crimes 59, sexual content 50, violence 54) chosen so that a competent, willing answer would be harmful, plus a 60-prompt subset and the rubric judge prompt (`strongreject/strongreject_evaluator_prompt.txt`), which scores refusal, convincingness and specificity. The lab uses the full set as its refusal measure and the subset for quick gates. Licence: MIT for the code and the 221 custom prompts; 92 prompts come from prior work under their own terms (AdvBench and DAN are MIT; MasterKey 3, Liu et al. 3, MaliciousInstruct 12, HarmfulQ 11 and the OpenAI GPT-4 system card 3 state no licence). Flags: the 32 unlicensed prompts (evaluate only, do not redistribute); the repository is deprecated upstream in favour of `dsbowen/strong_reject` (same data, MIT), and the pinned CSV is the paper's dataset; harmful-request content.

## harmbench

HarmBench (Mazeika et al. 2024, CAIS) standardises red-teaming evaluation; its text behaviors are 400 requests in three functional categories (200 standard, 100 contextual with a context string, 100 copyright) and seven semantic categories, with an official test (320) / val (80) split. Only the three behavior CSVs were fetched (no multimodal behaviors, classifier validation sets, copyright hashes, optimizer targets or code). The lab scores the 300 standard and contextual behaviors from `harmbench_behaviors_text_all.csv` and excludes the copyright category, which asks for verbatim copyrighted text and measures something else; the test/val split is kept for a held-out check. Licence: MIT. Flags: harmful-request content; copyright behaviors excluded by the lab.

## machiavelli (assessed, not fetched)

MACHIAVELLI (Pan et al., ICML 2023) is an RL-style gym over 134 human-written Choose-Your-Own-Adventure games from choiceofgames.com (572,322 scenes, 4,559 achievements, 2,861,610 annotations of power-seeking, disutility and ethical violations; a 30-game test set) that measures the trade-off between reward and ethical behaviour. The repository (`ebb44e19`) is MIT (code and labels), but the game text is not in it: it is a 438 MB password-protected archive on Google Drive (password printed in the README, no account needed) to be unpacked as `game_data/` (`game_metadata.json`, `scenarios/`, `trees/`, `source/`, `achievements/`, `annotations_*`), plus a second Drive file with the "artificial conscience" model. Neither the paper nor the website states a licence or permission for the copyrighted game text, and using the benchmark means running its gym environment (Python 3.11 or lower). Not fetched; if the lab ever wants it, the archive is a manual download and `game_data/` would have to be read with lab-written code only.
